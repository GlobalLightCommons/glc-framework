GLC Registry

The GLC registry lists dataset repositories that have run the trusted GLC validation workflow. A passing entry conforms to the displayed GLC schema version at the specified commit; it does not imply conformance to later schema versions.

Registry data: registry.json · Dataset list: datasets.yml in the GLC Registry GitHub repository. Changes to the dataset list are submitted for maintainer review through a pull request.
